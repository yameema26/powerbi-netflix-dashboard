# Netflix Data Analysis and Visualization

## Project Overview

This project analyses Netflix content data using Microsoft Power BI.
It combines data preparation, analytical calculations, and data
visualisation to explore content characteristics and trends.

A Power BI dashboard was developed to present the analysis in an
accessible visual format.

## Objectives

- Prepare and transform Netflix data using Power Query.
- Create a custom weighted score for analysis.
- Examine release trends and IMDb ratings.
- Explore voting patterns and runtime differences between movies
  and TV shows.
- Analyse age-certification categories.
- Present findings through a Power BI dashboard.

## Tools and Technologies

- Microsoft Power BI
- Power Query
- Data Visualisation

## Key Analysis Areas

### 1. Data Preparation
Prepared and transformed the Netflix dataset using Power Query.

### 2. Custom Analytical Calculation
Created a custom column to calculate a weighted score for analysis.

### 3. Content Analysis
Examined release trends, average IMDb scores, voting patterns,
runtime differences between movies and TV shows, and age-certification
ratings.

### 4. Dashboard Development
Built and formatted a Power BI dashboard to visualise the analysis.
