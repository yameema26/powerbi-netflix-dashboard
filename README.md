# Netflix Dashboard — Power BI

## Project Overview

This project presents a Netflix content analysis dashboard created using Microsoft Power BI. It focuses on exploring Netflix content data through data visualisation and interactive reporting.

## Project Objectives

* Explore Netflix content data.
* Present information through visual dashboards.
* Use data visualisation to make information easier to understand.
* Practise business intelligence and reporting skills.

## Tools and Technologies

* **Microsoft Power BI**
* **Data Visualisation**
* **GitHub**

## Project File

* `Netflix.pbix` — Power BI project file containing the dashboard and report.

## Key Skills

* Data visualisation
* Dashboard development
* Business intelligence
* Data analysis

## How to View the Project

1. Download `Netflix.pbix` from this repository.
2. Open the file using Microsoft Power BI Desktop.
3. Explore the dashboard and available report pages.

**Note:** GitHub does not display Power BI dashboards directly. Microsoft Power BI Desktop is required to open the `.pbix` file.
